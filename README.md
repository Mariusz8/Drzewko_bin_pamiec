🌳 BST (Binary Search Tree) in C++

Prosta, przejrzysta i zbalansowana koncepcyjnie implementacja Drzewa Poszukiwań Binarnych (BST) napisana w języku C++. Projekt zawiera podstawowe operacje wstawiania elementów oraz ich sortowania za pomocą przechodzenia drzewa w porządku rosnącym (In-order traversal).

🚀 Funkcjonalności

Struktura węzła (Node): Przechowuje wartość całkowitą (data) oraz wskaźniki na lewe i prawe dziecko.

Automatyczne wstawianie (insert): Wprowadza nowe elementy na odpowiednie miejsca zgodnie z zasadą BST (mniejsze wartości trafiają do lewego poddrzewa, większe lub równe do prawego).

Wyświetlanie posortowanych danych (display / inorder): Rekurencyjnie wypisuje elementy drzewa w porządku rosnącym.

🛠️ Wymagania

Do skompilowania i uruchomienia programu potrzebujesz:

Kompilatora obsługującego standard C++11 lub nowszy (np. g++, clang++, MSVC).

📦 Jak uruchomić?

Sklonuj repozytorium lub pobierz plik z kodem źródłowym (np. main.cpp).

Otwórz terminal w folderze z plikiem.

Skompiluj program poleceniem (np. przy użyciu GCC):

g++ -std=c++11 main.cpp -o bst_program


Uruchom wygenerowany plik wykonywalny:

Linux / macOS: ./bst_program

Windows: bst_program.exe

💡 Przykład użycia

Kod w pliku main.cpp tworzy przykładowe drzewo, wstawiając do niego liczby: 50, 30, 30, 20, 40, 70, 60, 80.

Wynik działania programu:

Elementy drzewa:
20 30 30 40 50 60 70 80
